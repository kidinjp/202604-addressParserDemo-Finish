# addressParser_Demo
このリポジトリは、Java から COBOL の住所解析処理を呼び出すデモプロジェクトです。

`addressParserDemo-0.0.1-SNAPSHOT.jar` は、入力された英語住所文字列から郵便番号・国名・都道府県・市区町村・町名・建物名などを抽出し、構造化データとして返す住所解析 API ＆ デモ Web アプリです。

バックエンドには Spring Boot（Java）を採用し、Web API と画面を提供しています。
既存の COBOL 住所判定ロジックを ProcessBuilder 経由で呼び出すことで、`レガシーな業務ロジックの再活用と、近代的な Web API 化`を実証する構成としています。

> * 本プロジェクトは、本格的な商用製品ではなく、技術検証・動作確認および GitHub 上での個人成果物としての公開を目的としたデモプロジェクトです。  
> * 開発期間：【2026/06〜2026/09】（※別途作成済みのCOBOL住所解析モジュールの組み込み・Web API化およびUI開発期間）

## 概要
### 開発の背景・目的
現職で携わった「ISO 20022（国際送金規格）」の構造化住所対応プロジェクトにて、  
英語住所から町名（TwnNm）や国名（Ctry）を正確に抽出する難しさと重要性を実感したことが開発のきっかけです。  

該プロジェクトでは台湾地域に特化した分析を行いましたが、特定地域にとどまらず、  
「最初からグローバル展開を見据え、より多種多様な住所表記（欧米・アジア圏などの表記習慣の違いに対応した）かつより細かく構造化対応できるロジック」を目指して設計・実装しました。  

また、将来的に私書箱やフロア番号など、より細かな住所情報の構造化が求められるケースを想定し、それらに対応できるロジックの設計・実装を検証することをテーマとしています。

### 本リポジトリ概要
本プロジェクトでは、以下の構成を実装しています。

* `input` フォルダ内の外部データを利用した住所解析
* Java アプリケーションから COBOL 実行ファイルを起動するデモ
* Spring Boot による REST API の提供
* HTML / CSS / JavaScript による Web UI
* Windows 環境でのローカル実行
* ユーザーが Java ランタイムを持っていない場合でも、`run.bat` から自動補完可能

## 実現する機能
* COBOL による住所解析・構造化ロジック
* Java / Spring Boot による Web API 化

### 1. 住所解析・構造化
入力された住所文字列を解析し、以下の情報へ分解します。 

| 項目 | 内容 |
| ---- | --- |
| POST CODE | 郵便番号 |
| COUNTRY | 国名 |
| COUNTRY SUB DIVISION | 都道府県/州 |
| DISTRICT NAME | 市区町村（区郡） |
| TOWN LOCATION NAME | 都道府名/エリア |
| TOWN NAME | 町域・町名 |
| ROOM | 部屋番号 |
| POST BOX | 私書箱 |
| FLOOR | 階/フロア |
| BUILDING NAME | 建物名・ビル名 |
| BUILDING NUMBER | 番地・号 |
| STREET NAME | 通り名・丁番地 |
| SUB DEPARTMENT | 部署（課/係） |
| DEPARTMENT | 部門（部/本部） |

### 2. UI/UX
デモ画面には、実際の検証作業を想定した以下の機能を搭載しています。

* レスポンシブデザイン
* 日本語 / 繁体字中国語 / 英語の多言語切替
* ライトモード / ダークモード切替機能を搭載
* 住所書き方ガイド
* 中国語住所 → 英語住所変換ガイド
* 日本・台湾・欧米圏のサンプル住所入力
* 解析結果ログ
* 処理ステータスの表示
* 処理時間・平均処理速度の表示（ms単位）
* 解析結果データの CSV ダウンロード（区切り文字：【;（セミコロン）】）
* JSON データの確認・コピー機能

### 3. パフォーマンス検証
1000件の住所データを使用したテストを実施し、以下を確認しています。  

* 1件あたり平均処理時間：約425ms
* エラー発生：0件

## 操作方法
### 依存環境と前提条件
* Java 11 以上を推奨
* Windows 環境を前提としたデモ
* `cobol/ADDRESS01.exe` が必要
* `input` フォルダ内の CSV ファイルを参照する構成

### クイックスタート（Windows）
1. `run.bat` をダブルクリックするか、コマンドプロンプトから実行してください。
2. `run.bat` は以下を自動で確認します。
   * `runtime\bin\java.exe` が存在するか
   * システムに `java` コマンドがあるか
   * どちらもない場合は `tools\fetch-jre.bat` を使って JRE を取得するか
3. 実行後、ブラウザで以下を開いて確認します。

```
http://localhost:9090/index.html
```

### 手動実行
```bat
java -jar addressParserDemo-0.0.1-SNAPSHOT.jar
```

### 注意事項
* 実行時に JRE が不足している場合は、ローカル環境へ`自動ダウンロード`されます。
* `cobol/ADDRESS01.exe` は本プロジェクトの動作に必須の実行ファイルです。

### 選定理由
現職の業務で初めて触れた COBOL の魅力と仕組みを深く理解するため、まずは核となる住所構造化ロジックの全般を COBOL で構築しました。  

その後、検証のしやすさやユーザー体験を考慮し、HTML/CSS/JavaScript を用いたWebインターフェースを作成しました。さらに、実務での利便性を意識し、前職のローカライズ経験を活かして日本語・繁体字中国語・英語の多言語対応 JSON や「中国語住所→英語変換ガイド」「英語住所の書き方ガイド」などの補助機能を組み込みました。  

最終的に、現職でスキルを磨いてきた Java（Spring Boot）を橋渡し役として全体を統合し、レガシー言語（COBOL）とモダンなWeb技術（Java / REST API）を組み合わせた実践的なアプリへと仕上げました。

## 処理フロー
1. run.bat を実行
 ↓ 
2. Java Runtime を確認
 ↓ 
3. 必要に応じて JRE を取得
 ↓ 
4. Spring Boot JAR を起動
 ↓ 
5. ブラウザから住所を入力
 ↓ 
6. REST API に住所データを送信
 ↓ 
7. Java が ProcessBuilder で COBOL を起動
 ↓ 
8. COBOL が住所を解析
 ↓ 
9. 解析結果を Java が取得
 ↓ 
10. JSON としてブラウザへ返却
 ↓ 
11. 解析結果・処理時間・ログを画面表示
